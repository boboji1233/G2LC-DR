# Claim Contract

This contract implements research-plan §1, §4 and task B-02. It remains binding for
code, documentation, experiments and manuscripts.

## Permitted, when supported by the corresponding checks

- For a predeclared image-observable evidence language, determine whether available
  annotation operators can execute a target guideline family.
- Find an exact minimum-cost scheme on finite problems, or report a clearly labelled
  feasible/approximate result for scalable solvers.
- Emit machine-checkable executable, missing-evidence and out-of-specification
  certificates.
- Load an unseen guideline program without retraining an evidence model only when all
  its predicates remain inside the declared evidence language.
- Report annotation cost, stability and coverage trade-offs after real inputs and
  protocols have been run and logged.

## Prohibited

- Support for arbitrary future guidelines or clinical variables unavailable in CFP/UWF.
- Clinical deployment, prospective validation, state-of-the-art or expert-equivalence
  claims without the required real experiments.
- Presenting a new backbone, loss, graph, attention or LLM component as the core G2LC
  contribution.
- Treating missing labels as negative, DDR and MMRDR-CFP as independent domains, or
  separate datasets as evidence of guideline transport.
- Using MAPLES/MESSIDOR target labels or held-out target actions for model selection,
  calibration, thresholding or rule tuning.
- Treating synthetic rules, LLM output, or this research plan itself as clinically
  validated guideline ground truth.

## Current claim level

Only synthetic software correctness may be claimed. No real dataset is present, no
Oracle protocol has run, and no clinical or performance result exists.

Stage 1.5 proves decision sufficiency only under the declared finite evidence,
feasibility, derivation, modality, and guideline semantics. It does not prove that the
declared evidence language, synthetic rules, costs, or modalities are clinically valid or
complete, and it does not establish visual learnability.
